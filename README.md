# محاكي بوابات الدفع

هذا المشروع يوفر محاكيًا لبوابات الدفع المختلفة، مما يسمح باختبار بطاقات الدفع وإرسالها إلى بوابات وهمية أو حقيقية (حسب إعدادات البوابة) واستقبال ردودها.

## محتويات المشروع

-   `final_simulator.py`: الملف الرئيسي للمحاكي الذي يقوم بتحميل وتشغيل البوابات.
-   `Gataway-cf/`: مجلد يحتوي على ملفات البوابات المختلفة، مقسمة حسب نوع البوابة (Auth, Charge, LookUp).
-   `requirements.txt`: ملف يحتوي على المكتبات المطلوبة لتشغيل المحاكي.

## كيفية الاستخدام

1.  **استنساخ المستودع:**

    ```bash
    git clone https://github.com/ymahmdn67-stack/Mibot.git
    cd Mibot
    ```

2.  **تثبيت المتطلبات:**

    تأكد من تثبيت Python 3.x. ثم قم بتثبيت المكتبات المطلوبة:

    ```bash
    pip install -r requirements.txt
    ```

3.  **تشغيل المحاكي:**

    ```bash
    python3 final_simulator.py
    ```

4.  **إدخال بيانات البطاقة:**

    سيطلب منك المحاكي إدخال بيانات البطاقة بصيغة `cc|mm|yy|cvv`. يمكنك إدخال بيانات بطاقة اختبار أو الضغط على `Enter` لاستخدام البيانات الافتراضية.

    مثال:
    `5334670035839519|10|28|948`

5.  **اختيار المجموعة:**

    سيتم عرض قائمة بمجموعات البوابات المتاحة. يمكنك اختيار رقم مجموعة معينة لتشغيل جميع البوابات داخلها، أو كتابة `all` لتشغيل جميع البوابات المكتشفة.

    مثال:
    `1` (لتشغيل مجموعة B3 Auth)
    `all` (لتشغيل جميع البوابات)

## المخرجات

بعد الانتهاء من التشغيل، سيعرض المحاكي جدولاً يلخص نتائج كل بوابة، بما في ذلك:

-   **البوابة:** اسم البوابة.
-   **الحالة:** حالة الرد (مثال: Success, Declined, Error).
-   **الوقت:** الوقت المستغرق لتشغيل البوابة.
-   **الرد:** رسالة الرد المستلمة من البوابة.
